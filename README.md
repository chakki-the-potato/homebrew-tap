# chakki-the-potato/homebrew-tap

[restage](https://github.com/chakki-the-potato/restage) 설치용 Homebrew tap.

```bash
brew install chakki-the-potato/tap/restage
open $(brew --prefix restage)/restage.app
```

소스를 받아 이 컴퓨터에서 빌드한다. 직접 빌드한 앱은 Gatekeeper가 막지 않으므로
"확인되지 않은 개발자" 경고가 뜨지 않는다.

macOS 13 이상과 Xcode 명령줄 도구가 필요하다.
